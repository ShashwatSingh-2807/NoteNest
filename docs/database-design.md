# Database Design

**Status:** Not designed yet.

This document will contain the approved database design after requirements and module ownership are reviewed.

## Design Checklist
- Identify entities from confirmed requirements.
- Define attributes and suitable data types.
- Define primary keys and foreign-key relationships.
- Decide uniqueness, nullability, and deletion constraints.
- Consider indexes for common search/filter operations.
- Review relationships among users, academic categories, resources, moderation, and downloads.

No database schema is approved here. Do not create tables based only on assumptions. Update this document after the team reviews the ER diagram and agrees on the model.
